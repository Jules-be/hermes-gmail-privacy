Hermes Gmail

Hermes Gmail is a personal, single-user assistant. It reads the owner's Gmail mailbox in read-only mode to help with a daily summary, to highlight messages that need attention and to suggest reminders.

What it does

  • Reads recent messages with the Gmail read-only scope (gmail.readonly) and classifies them by category and priority.
  • Builds a short morning summary and rare alerts for genuinely urgent messages.
  • Answers the owner's questions about their own mailbox and proposes reminders, which the owner must approve.

What it never does

  • It cannot send, draft, delete, archive, label or mark messages as read.
  • It does not read attachments and does not follow instructions found inside emails.
  • It is not offered to other users: it runs on the owner's own device with the owner's own Google account.

Details: see the Privacy Policy.
