Privacy Policy – Hermes Gmail

Last updated: 26 October 2026.

Hermes Gmail is a personal application used only by its owner, with the owner's own Google account. This policy explains what data the application accesses, how it is used and how to remove it.

Data accessed

With the owner's consent, the application requests a single Google permission: https://www.googleapis.com/auth/gmail.readonly (view email messages and settings). Through it, it reads the sender, subject, date, labels and text of recent messages. It does not access attachments and cannot modify the mailbox.

How the data is used

  • To classify messages by category and priority, to summarise them, and to detect deadlines or requested actions.
  • To produce a daily summary and rare alerts for the owner, and to answer the owner's questions about their own mailbox.
  • For some messages, the text (truncated) is sent to an AI language model service chosen and configured by the owner, solely to classify and summarise it. No data is used for advertising, and no human reads it.

Storage and retention

The application stores only the sender, subject, date, labels, the generated summary and the extracted action of each message, on the owner's own device, in a private folder. Message bodies are not stored. Analyses older than 90 days are deleted. OAuth tokens are stored locally with restricted file permissions.

Sharing

Data is not sold, shared with third parties or transferred, except to the AI service mentioned above (to perform the classification requested by the owner) and as required by law.

Google API Services User Data Policy

Hermes Gmail's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. The application also provides commands to revoke the token and to erase all locally stored data.

Contact

Questions: open an issue at github.com/Jules-be/hermes-gmail-privacy.

Version française (résumé)

Hermes Gmail est une application personnelle, utilisée uniquement par son propriétaire. Elle demande la seule autorisation Google de lecture seule de Gmail (gmail.readonly), ne lit pas les pièces jointes et ne peut rien modifier dans la boîte. Elle conserve sur l'appareil du propriétaire l'expéditeur, l'objet, la date, les libellés, un résumé et l'action extraite (jamais le corps du message), pendant 90 jours au plus. Pour certains messages, un extrait du texte est envoyé à un service d'IA configuré par le propriétaire, uniquement pour les classer et les résumer. Aucune donnée n'est vendue ni partagée. L'accès se révoque à tout moment sur myaccount.google.com/permissions.
